# Character sprites

Source: **MetroCity — Free Topdown Character Pack** by JIK-A-4
https://jik-a-4.itch.io/metrocity-free-topdown-character-pack

License: **CC0 1.0 Universal** (public domain dedication). Free for personal and
commercial use, no attribution required. Credit is given here anyway, because
the pack is good and the author asked nicely.

Sheet layout: 112x96 px, 7 columns x 3 rows, each frame 16x32.
Row 0 = facing down, row 1 = facing side, row 2 = facing up.
Column 0 = idle, columns 1-6 = walk cycle.
